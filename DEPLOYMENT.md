# Deployment

This app is configured for Render as a single Node web service.

## Render values

- Environment: `Node`
- Build Command: `npm ci && npm run build`
- Start Command: `npm start`
- Public URL / CORS origin: `https://tontine-app.onrender.com`

## Environment variables

- `NODE_ENV=production`
- `NODE_VERSION=22.12.0`
- `PORT=10000`
- `SESSION_SECRET` generated by Render
- `CORS_ORIGIN=https://tontine-app.onrender.com`
- `VITE_API_URL` blank, because the frontend and API are served from the same service

Render can also read these settings from `render.yaml`.
